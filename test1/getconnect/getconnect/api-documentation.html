Getting Started

Learn how to integrate with GetConnect.Web API in minutes

Get API Key

Create an account and generate your API key from the dashboard

Make First Request

Use curl or your favorite HTTP client to make your first API call

Integrate

Use our SDKs or implement the REST API in your application

Base URL

All API requests should be made to the following base URL:

Base URL 
https://api.getconnect.web/v1

Quick Example

Here's a quick example of submitting a task via API:

cURL Example 
curl -X POST https://api.getconnect.web/v1/tasks \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "data_processing",
    "payload": {
      "dataset": "sensor_data.csv",
      "operation": "aggregate"
    },
    "priority": "high"
  }'

Authentication

Secure your API requests with Bearer token authentication

All API requests require authentication using a Bearer token. You can generate API keys from your account dashboard.

POST /auth/token

Generate a new access token using your API credentials.

Request Parameters

Parameter Type Required Description
api_key string Required Your API key from account settings
api_secret string Required Your API secret from account settings
expires_in integer Optional Token expiry in seconds (default: 3600)
Request Example 
{
  "api_key": "your_api_key_here",
  "api_secret": "your_api_secret_here",
  "expires_in": 7200
}
200 OK Response 
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 7200,
  "scope": "tasks:read tasks:write nodes:read"
}

Using the Access Token

Include the access token in the Authorization header of all subsequent requests:

Authentication Header 
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Tasks API

Manage distributed task execution through the API

POST /tasks

Submit a new task for distributed execution.

Request Body

Parameter Type Required Description
type string Required Task type identifier
payload object Required Task data and parameters
priority string Optional low, medium, high (default: medium)
callback_url string Optional Webhook URL for task completion
metadata object Optional Additional task metadata
Request Example 
{
  "type": "data_processing",
  "payload": {
    "operation": "aggregate",
    "data": [1, 2, 3, 4, 5],
    "aggregation": "sum"
  },
  "priority": "high",
  "callback_url": "https://your-app.com/webhooks/task-complete",
  "metadata": {
    "user_id": "12345",
    "batch_id": "batch-001"
  }
}
201 Created Response 
{
  "task_id": "task_abc123def456",
  "status": "queued",
  "estimated_completion": "2024-12-15T10:30:00Z",
  "node_assignment": "node-7",
  "queue_position": 5,
  "created_at": "2024-12-15T10:00:00Z"
}

Python SDK Example

Python Example 
from getconnect import GetConnectClient

# Initialize client
client = GetConnectClient(api_key="your_api_key")

# Submit a task
task = client.submit_task(
    type="data_processing",
    payload={
        "dataset": "sensor_data.csv",
        "operation": "aggregate",
        "aggregation": "average"
    },
    priority="high"
)

print(f"Task submitted: {task.id}")

# Check task status
status = client.get_task_status(task.id)
print(f"Task status: {status.status}")
print(f"Progress: {status.progress}%")

# Get task result when completed
if status.status == "completed":
    result = client.get_task_result(task.id)
    print(f"Result: {result}")

JavaScript SDK Example

JavaScript Example 
import { GetConnectClient } from '@getconnect/web-sdk';

// Initialize client
const client = new GetConnectClient({
  apiKey: 'your_api_key',
  baseURL: 'https://api.getconnect.web/v1'
});

// Submit a task
const task = await client.submitTask({
  type: 'image_processing',
  payload: {
    imageUrl: 'https://example.com/image.jpg',
    operations: ['resize', 'compress'],
    outputFormat: 'webp'
  },
  priority: 'medium'
});

console.log(`Task submitted: ${task.id}`);

// Monitor task completion
const checkStatus = setInterval(async () => {
  const status = await client.getTaskStatus(task.id);
  console.log(`Progress: ${status.progress}%`);
  
  if (status.status === 'completed') {
    clearInterval(checkStatus);
    const result = await client.getTaskResult(task.id);
    console.log('Task completed:', result);
  }
}, 5000);
