API Documentation

The GetConnect.Web REST API lets you programmatically manage distributed tasks, monitor nodes, and retrieve analytics. All requests use HTTPS and return JSON responses.

REST
API Architecture
v2.4
Current Version
JSON
Response Format
All API endpoints require authentication via Bearer token. Include your API key in every request header.
Authentication

Authentication

GetConnect uses API keys for authentication. Pass your key in the Authorization header as a Bearer token.

Request Header

HTTP
Authorization: Bearer gc_live_xxxxxxxxxxxxxxxxxxxx
Content-Type: application/json
X-API-Version: 2024-01

Example with cURL

cURL
curl -X GET "https://api.getconnect.web/v2/tasks" \
  -H "Authorization: Bearer gc_live_xxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json"
Never expose your API key in client-side code. Use environment variables or a backend proxy.
Base URL

Base URL

All API requests should be made to the following base URL. We support both production and sandbox environments.

Endpoints

Tasks API

Tasks API

Manage distributed tasks — create, monitor, update, and delete tasks across your node cluster.

List Tasks

GET /tasks Returns paginated list of all tasks

Retrieve a paginated list of tasks with optional filters.

QUERY PARAMETERS

ParameterTypeRequiredDescription
statusstringoptionalFilter by: pending, processing, completed, failed
limitintegeroptionalResults per page (default: 20, max: 100)
pageintegeroptionalPage number (default: 1)
node_idstringoptionalFilter tasks by node ID
cURL
curl -X GET "https://api.getconnect.web/v2/tasks?status=processing&limit=20" \
  -H "Authorization: Bearer gc_live_xxxx"
200 OK400 Error
JSON Response

Create Task

POST /tasks Submit a new task for distribution

Submit a new task. The AI load balancer will automatically assign it to the optimal node.

REQUEST BODY

FieldTypeRequiredDescription
namestringrequiredHuman-readable task name
typestringrequiredTask type: compute, ml, render, sync
prioritystringoptionalhigh | medium | low (default: medium)
payloadobjectrequiredTask-specific data payload
node_idstringoptionalForce assignment to specific node
webhook_urlstringoptionalURL to notify on completion
cURL
curl -X POST "https://api.getconnect.web/v2/tasks" \
  -H "Authorization: Bearer gc_live_xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "ML Model Training",
    "type": "ml",
    "priority": "high",
    "payload": { "model": "bert-base", "epochs": 10 },
    "webhook_url": "https://yourapp.com/webhook"
  }'
201 Created400 Error
JSON Response
{
  "success": true,
  "data": {
    "id": "task_xyz789",
    "status": "queued",
    "node_id": "node_3",
    "estimated_completion": "2025-01-15T10:45:00Z",
    "queue_position": 4
  }
}

Get Task

GET /tasks/{task_id} Get details of a specific task
cURL
curl -X GET "https://api.getconnect.web/v2/tasks/task_abc123" \
  -H "Authorization: Bearer gc_live_xxxx"

Delete Task

DELETE /tasks/{task_id} Cancel and delete a task
Deleting a running task will immediately stop execution. This action cannot be undone.
cURL
curl -X DELETE "https://api.getconnect.web/v2/tasks/task_abc123" \
  -H "Authorization: Bearer gc_live_xxxx"

Webhooks

Webhooks

Receive real-time notifications when task status changes. Register a webhook URL when creating a task or via the dashboard.

Webhook Payload

JSON Payload
{
  "event": "task.completed",
  "timestamp": "2025-01-15T10:45:00Z",
  "data": {
    "task_id": "task_xyz789",
    "status": "completed",
    "duration_ms": 4820,
    "node_id": "node_3",
    "result_url": "https://api.getconnect.web/v2/tasks/task_xyz789/result"
  }
}
Verify webhook authenticity by checking the X-GetConnect-Signature header against your webhook secret using HMAC-SHA256.

Quick Start (JavaScript)

JavaScript
import { GetConnect } from '@getconnect/sdk';

const client = new GetConnect({ apiKey: 'gc_live_xxxx' });

// Create a task
const task = await client.tasks.create({
  name: 'ML Training',
  type: 'ml',
  priority: 'high',
  payload: { model: 'bert-base', epochs: 10 }
});

// Poll for completion
const result = await client.tasks.waitForCompletion(task.id);
console.log('Done:', result);
